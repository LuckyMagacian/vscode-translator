# 禁用Hover触发翻译变更计划

## 变更目标

移除HoverProvider自动翻译功能，只保留手动选中文本后执行翻译命令。

## 变更原因

1. **避免重复翻译**：HoverProvider会导致同一文本被多次翻译（浪费API调用）
2. **用户体验优化**：用户更倾向于主动控制翻译时机
3. **简化功能**：减少不必要的自动触发逻辑
4. **保留缓存优势**：手动翻译仍然享受缓存优化

## 变更内容

### 1. 移除HoverProvider注册

**文件**：`src/extension.ts`

**改动**：
- 删除 `TranslatorHoverProvider` 的导入
- 删除 `registerHoverProvider` 注册

**原代码**：
```typescript
import { TranslatorHoverProvider } from './translatorHoverProvider';
context.subscriptions.push(vscode.languages.registerHoverProvider('*', new TranslatorHoverProvider()));
```

**新代码**：
```typescript
// 不导入和注册HoverProvider
```

### 2. 更新激活事件

**文件**：`package.json`

**改动**：
- 移除 `onStartupFinished`（不再需要启动后激活）
- 只保留命令激活事件

**原配置**：
```json
"activationEvents": [
    "onStartupFinished",
    "onCommand:translator.translate",
    ...
]
```

**新配置**：
```json
"activationEvents": [
    "onCommand:translator.translate",
    "onCommand:translator.replaceWithTranslation",
    "onCommand:translator.toggleCaptureWord"
]
```

### 3. 移除相关配置项（可选）

**文件**：`package.json`

**改动**：
- 移除 `translator.captureWord` 配置项
- 移除 `translator.toggleCaptureWord` 命令

**说明**：这些配置项和命令专用于Hover功能，移除后简化配置。

### 4. 清理无用代码

**文件**：`src/translatorHoverProvider.ts`

**改动**：
- 可以删除整个文件（不再需要）
- 或保留作为历史参考

## 影响评估

| 功能 | 当前状态 | 变更后状态 |
|------|----------|------------|
| Hover自动翻译 | ✅ 启用 | ❌ 禁用 |
| 手动翻译命令 | ✅ 正常 | ✅ 正常 |
| 替换翻译命令 | ✅ 正常 | ✅ 正常 |
| 翻译缓存 | ✅ 启用 | ✅ 启用 |
| 扩展激活时机 | 启动后 | 执行命令时 |

## 用户体验变化

**优化前**：
- 鼠标悬停在单词上自动翻译
- 同一文本可能被多次翻译
- 用户无法控制翻译时机

**优化后**：
- 选中文本后执行 `Translate` 命令
- 只在用户主动触发时翻译
- 翻译结果输出到OutputChannel
- 缓存避免重复API调用
