# 设计说明书 - 日志开关配置

## 1. 设计概述

本设计实现翻译日志的开关控制,允许用户根据需要启用或禁用日志输出。

### 1.1 设计目标

- 新增日志开关配置项
- 在基类中统一处理日志开关逻辑
- 保持向后兼容,默认开启日志

### 1.2 技术方案

- 在 `BaseTranslator` 基类中添加日志开关属性
- 修改基类的日志方法,检查开关后再输出
- 在 `TranslatorFactory` 中读取配置并传递给翻译器

### 2.3 BaseTranslator 类设计

#### 2.3.1 属性变更

```typescript
export abstract class BaseTranslator implements ITranslationProvider {
    abstract readonly name: string;
    abstract readonly displayName: string;
    abstract translate(source: string, outputChannel?: vscode.OutputChannel): Promise<string>;

    protected enableLog: boolean;  // 新增

    constructor(enableLog: boolean = true) {
        this.enableLog = enableLog;
    }
}
```

#### 2.3.2 日志方法变更

```typescript
/**
 * 输出日志到OutputChannel
 * @param outputChannel 输出管道
 * @param message 日志消息
 */
protected log(outputChannel: vscode.OutputChannel | undefined, message: string): void {
    if (this.enableLog && outputChannel) {
        outputChannel.appendLine(message);
    }
}

/**
 * 输出API响应详情
 * @param outputChannel 输出管道
 * @param title 标题
 * @param data 数据对象
 */
protected logApiResponse(outputChannel: vscode.OutputChannel | undefined, title: string, data: any): void {
    if (this.enableLog && outputChannel) {
        outputChannel.appendLine(`=== ${title} ===`);
        outputChannel.appendLine(JSON.stringify(data, null, 2));
        outputChannel.appendLine('');
    }
}

/**
 * 输出错误信息
 * @param outputChannel 输出管道
 * @param title 错误标题
 * @param error 错误对象
 */
protected logError(outputChannel: vscode.OutputChannel | undefined, title: string, error: unknown): void {
    if (this.enableLog && outputChannel) {
        outputChannel.appendLine(`ERROR: ${title}`);
        if (error instanceof Error) {
            outputChannel.appendLine(error.stack || error.message);
        } else {
            outputChannel.appendLine(String(error));
        }
        outputChannel.appendLine('');
    }
}
```

### 2.4 SiliconFlowTranslator 类变更

构造函数需要调用父类构造函数:

```typescript
constructor(
    apiKey: string,
    model: string = 'tencent/Hunyuan-MT-7B',
    baseUrl: string = 'https://api.siliconflow.cn/v1',
    systemPrompt?: string,
    firstLanguage: string = '中文',
    secondLanguage: string = '英文',
    enableLog: boolean = true  // 新增参数
) {
    super(enableLog);  // 调用父类构造函数
    this.apiKey = apiKey;
    this.model = model;
    this.baseUrl = baseUrl;
    this.firstLanguage = firstLanguage;
    this.secondLanguage = secondLanguage;

    // 确定提示词来源并替换占位符
    const promptTemplate = systemPrompt || SiliconFlowTranslator.DEFAULT_PROMPT_TEMPLATE;
    this.systemPrompt = this.replacePromptPlaceholders(promptTemplate);
}
```

### 2.6 TranslatorFactory 变更

更新 `create` 方法,读取并传递日志配置:

```typescript
static create(provider: string, config: vscode.WorkspaceConfiguration): ITranslationProvider {
    // 读取日志配置
    const enableLog = config.get<boolean>('enableLog', true);

    switch (provider) {
        case 'youdao':
            return new YoudaoTranslator(enableLog);

        case 'siliconflow':
            const apiKey = config.get<string>('siliconflow.apiKey', '');
            const model = config.get<string>('siliconflow.model', 'tencent/Hunyuan-MT-7B');
            const baseUrl = config.get<string>('siliconflow.baseUrl', 'https://api.siliconflow.cn/v1');
            const systemPrompt = config.get<string>('siliconflow.systemPrompt', '');
            const firstLanguage = config.get<string>('firstLanguage', '中文');
            const secondLanguage = config.get<string>('secondLanguage', '英文');

            return new SiliconFlowTranslator(
                apiKey,
                model,
                baseUrl,
                systemPrompt,
                firstLanguage,
                secondLanguage,
                enableLog  // 传递日志配置
            );

        default:
            return new YoudaoTranslator(enableLog);
    }
}
```

## 3. 实现要点

### 3.1 日志开关检查

- **时机**: 在每次调用日志方法时检查
- **条件**: `this.enableLog && outputChannel`
- **性能**: 关闭日志时,完全跳过日志构建和输出

### 3.2 向后兼容

- 使用默认参数 `enableLog = true`
- 未配置时,保持现有行为

### 3.3 统一处理

- 在基类中统一处理日志开关
- 所有翻译器自动继承此功能

## 4. 测试用例

### 4.1 配置项测试

| 测试项 | 预期结果 |
|--------|----------|
| 未配置 enableLog | 使用默认值 true,输出日志 |
| 配置 enableLog = true | 输出所有日志 |
| 配置 enableLog = false | 不输出任何日志 |

### 4.2 日志输出测试

| 场景 | enableLog | outputChannel | 预期行为 |
|------|-----------|---------------|----------|
| 开启日志 | true | 存在 | 输出日志 |
| 关闭日志 | false | 存在 | 不输出日志 |
| 无输出通道 | true | undefined | 不输出日志 |
| 默认配置 | 未设置 | 存在 | 输出日志 |
