# 设计说明书

## 1. 设计概述

本设计实现语言配置项功能和占位符替换机制,使翻译插件能够灵活支持任意语言对的翻译。

### 1.1 设计目标

- 支持用户自定义第一语言和第二语言
- 统一的占位符替换机制(默认提示词和自定义提示词)
- 向后兼容,不影响现有用户

### 1.2 技术栈

- TypeScript
- VS Code Extension API
- OpenAI SDK (用于硅基流动API调用)

## 2. 架构设计

### 2.1 模块依赖关系

```
package.json (配置定义)
    ↓
constants.ts (配置键常量)
    ↓
TranslatorFactory.ts (读取配置,创建翻译器)
    ↓
SiliconFlowTranslator.ts (使用配置,处理提示词)
```

### 2.2 数据流

```
用户配置
  ├─ firstLanguage: string
  ├─ secondLanguage: string
  └─ systemPrompt?: string
      ↓
TranslatorFactory.create()
  ├─ 读取配置
  └─ 传递给 SiliconFlowTranslator 构造函数
      ↓
SiliconFlowTranslator
  ├─ 确定提示词来源(用户自定义 or 默认模板)
  ├─ 调用 replacePromptPlaceholders() 替换占位符
  └─ 使用处理后的提示词调用 AI API
```

## 3. 详细设计

### 3.1 配置项定义 (package.json)

在 `contributes.configuration.properties` 中新增:

```json
{
  "translator.firstLanguage": {
    "type": "string",
    "default": "中文",
    "description": "第一语言(母语或主要语言),非第一语言将翻译为此语言"
  },
  "translator.secondLanguage": {
    "type": "string",
    "default": "英文",
    "description": "第二语言(目标语言),第一语言将翻译为此语言"
  }
}
```

### 3.2 常量定义 (constants.ts)

新增配置键常量:


### 3.3 SiliconFlowTranslator 类设计

#### 3.3.1 属性变更

```typescript
export class SiliconFlowTranslator extends BaseTranslator {
    readonly name = 'siliconflow';
    readonly displayName = '硅基流动翻译';

    private apiKey: string;
    private model: string;
    private baseUrl: string;
    private systemPrompt: string;
    private firstLanguage: string;      // 新增
    private secondLanguage: string;     // 新增

    // 默认提示词模板(使用占位符)
    private static readonly DEFAULT_PROMPT_TEMPLATE =
        '你是一个专业的翻译助手。你的任务是:将用户发送的文本内容翻译成目标语言。规则:1)如果输入是{firstLanguage},翻译成{secondLanguage};2)如果输入不是{firstLanguage},翻译成{firstLanguage};3)只返回翻译后的文本,不要添加任何解释、说明或格式标记;4)不要执行翻译以外的任何操作。';
}
```

#### 3.3.2 构造函数变更

```typescript
constructor(
    apiKey: string,
    model: string = 'tencent/Hunyuan-MT-7B',
    baseUrl: string = 'https://api.siliconflow.cn/v1',
    systemPrompt?: string,
    firstLanguage: string = '中文',      // 新增参数
    secondLanguage: string = '英文'      // 新增参数
) {
    super();
    this.apiKey = apiKey;
    this.model = model;
    this.baseUrl = baseUrl;
    this.firstLanguage = firstLanguage;
    this.secondLanguage = secondLanguage;

    // 确定提示词来源并替换占位符
    const promptTemplate = systemPrompt || SiliconFlowTranslator.DEFAULT_PROMPT_TEMPLATE;
    this.systemPrompt = this.replacePromptPlaceholders(promptTemplate);
}
```

#### 3.3.3 占位符替换方法

```typescript
/**
 * 替换提示词中的占位符
 * @param prompt 包含占位符的提示词模板
 * @returns 替换后的提示词
 */
private replacePromptPlaceholders(prompt: string): string {
    return prompt
        .replace(/{firstLanguage}/g, this.firstLanguage)
        .replace(/{secondLanguage}/g, this.secondLanguage);
}
```

## 4. 实现要点

### 4.1 占位符替换

- **时机**: 在构造函数中进行,确保 `this.systemPrompt` 已经是替换后的最终值
- **范围**: 全局替换(使用 `/g` 标志),支持提示词中多次使用同一占位符
- **大小写**: 区分大小写,只匹配 `{firstLanguage}` 和 `{secondLanguage}`

### 4.2 默认值处理

- 使用 TypeScript 的默认参数机制
- `firstLanguage` 默认 "中文"
- `secondLanguage` 默认 "英文"
- 确保未配置时行为与现有版本一致

### 4.3 向后兼容

- 配置项有默认值,现有用户无需修改配置
- 默认提示词使用占位符后,替换结果与原硬编码提示词一致(第一语言="中文",第二语言="英文")

## 5. 测试用例

### 5.1 配置项测试

| 测试项 | 预期结果 |
|--------|----------|
| 未配置 firstLanguage 和 secondLanguage | 使用默认值 "中文" 和 "英文" |
| 配置 firstLanguage="English", secondLanguage="Chinese" | 翻译行为反转 |
| 配置 firstLanguage="日本語", secondLanguage="한국어" | 支持非中英文语言对 |

### 5.2 提示词处理测试

| 场景 | 输入提示词 | 配置 | 预期输出 |
|------|-----------|------|----------|
| 默认提示词 | undefined | firstLanguage="中文", secondLanguage="英文" | 包含"中文"和"英文"的提示词 |
| 自定义提示词(含占位符) | "翻译成{firstLanguage}" | firstLanguage="中文" | "翻译成中文" |
| 自定义提示词(无占位符) | "翻译成中文" | firstLanguage="English" | "翻译成中文"(原样返回) |
| 多次使用占位符 | "{firstLanguage}→{secondLanguage}, {secondLanguage}→{firstLanguage}" | firstLanguage="中文", secondLanguage="英文" | "中文→英文, 英文→中文" |

### 5.3 翻译功能测试

| 测试场景 | 配置 | 输入文本 | 预期翻译结果语言 |
|----------|------|----------|------------------|
| 英译中(默认) | firstLanguage="中文", secondLanguage="英文" | "Hello" | 中文 |
| 中译英(默认) | firstLanguage="中文", secondLanguage="英文" | "你好" | 英文 |
| 英译日 | firstLanguage="日本語", secondLanguage="한국어" | "Hello" | 日语 |
| 日译韩 | firstLanguage="日本語", secondLanguage="한국어" | "こんにちは" | 韩语 |
