# VSCode扩展性能优化计划

## 优化目标

减少扩展体积和加载时间，提升用户体验。

## 问题分析

| 问题 | 当前状态 | 影响 |
|------|----------|------|
| 激活事件 | 使用 `*`（全局激活） | VSCode启动时加载，影响启动性能 |
| 打包方式 | 未打包，2457个文件 | 文件数量多，加载慢，体积大(3.32MB) |
| JS文件数 | 673个JS文件 | 每个文件都需要单独加载 |
| 未排除文件 | 无 `.vscodeignore` | 包含不必要的文件（测试、文档等） |

## 优化方案

### 1. 优化激活事件

**原配置**（package.json）：
```json
"activationEvents": [
    "*",
    "onCommand:translator.translate",
    "onCommand:translator.toggleCaptureWord"
]
```

**优化后**：
```json
"activationEvents": [
    "onStartupFinished",  // VSCode启动完成后激活
    "onCommand:translator.translate",
    "onCommand:translator.replaceWithTranslation",
    "onCommand:translator.toggleCaptureWord"
]
```

**说明**：
- 移除 `*`，避免启动时立即加载
- 使用 `onStartupFinished`，在VSCode启动完成后激活（HoverProvider需要）
- 保持命令激活事件

### 2. 添加Webpack打包

**目标**：
- 将所有JS文件打包为单个bundle
- 减少文件数量（从673个到1个）
- 减小体积（预计减少50%以上）

**实施步骤**：
1. 安装webpack依赖
2. 创建webpack.config.js
3. 修改package.json构建脚本
4. 配置extensionMainEntry

### 3. 配置.vscodeignore

**排除内容**：
- 测试文件（test/**、**/*.test.ts）
- 文档文件（docs/**、*.md）
- 开发配置（.vscode/**、tsconfig.json）
- 源代码（src/**）
- Git文件（.git/**、.gitignore）

## 代码改动清单

| 文件 | 改动类型 | 改动内容 |
|------|----------|----------|
| `package.json` | 修改 | 更新激活事件、添加webpack脚本、配置main入口 |
| `webpack.config.js` | 新增 | Webpack打包配置 |
| `.vscodeignore` | 新增 | 排除不必要的文件 |

## 预期效果

| 指标 | 当前 | 优化后 |
|------|------|--------|
| 文件数量 | 2457个 | ~50个 |
| JS文件数 | 673个 | 1个 |
| 体积 | 3.32MB | ~1.5MB |
| 加载时间 | 较慢 | 显著提升 |

## 验证方案

1. 打包后检查文件数量和体积
2. 安装优化后的扩展，测试启动时间
3. 验证所有功能正常工作
