# 翻译组件重构设计说明

**日期**: 2026-06-22
**目标**: 将翻译组件抽象为可扩展架构,支持多种翻译服务

---

## 1. 设计目标

- 抽象翻译接口,支持多种翻译服务提供商
- 当前实现:有道翻译
- 新增实现:硅基流动翻译
- 用户可配置选择翻译服务

## 2. 架构设计

### 2.1 核心接口

```typescript
/**
 * 翻译服务接口
 */
interface ITranslationProvider {
    /**
     * 提供商名称(唯一标识)
     */
    readonly name: string;

    /**
     * 提供商显示名称
     */
    readonly displayName: string;

    /**
     * 翻译文本
     * @param source 源文本
     * @param outputChannel 输出管道(可选)
     * @returns 翻译结果
     */
    translate(source: string, outputChannel?: vscode.OutputChannel): Promise<string>;
}
```

### 2.2 文件结构

```
src/
├── translators/
│   ├── ITranslationProvider.ts    # 翻译接口定义
│   ├── BaseTranslator.ts          # 基础翻译类(公共逻辑)
│   ├── YoudaoTranslator.ts        # 有道翻译实现
│   ├── SiliconFlowTranslator.ts   # 硅基流动翻译实现
│   └── TranslatorFactory.ts       # 翻译器工厂
├── translator.ts                   # 主控制器(更新)
└── constants.ts                    # 配置常量(更新)
```

### 2.3 类图

```
ITranslationProvider (interface)
         ↑
    BaseTranslator (abstract)
      ↗         ↖
YoudaoTranslator  SiliconFlowTranslator
```

## 3. 实现细节

### 3.1 有道翻译 (现有)

**API**: `https://fanyi.youdao.com/translate?&doctype=json&type=AUTO&i={text}`

**响应格式**:
```json
{
  "translateResult": [
    [{"src": "hello", "tgt": "你好"}]
  ]
}
```

### 3.2 硅基流动翻译 (新增)

**服务类型**: AI翻译服务(基于大语言模型)

**API**: OpenAI兼容接口
- **端点**: `https://api.siliconflow.cn/v1/chat/completions`
- **认证**: Bearer Token (API Key)
- **使用包**: `openai` npm包

**请求格式**:
```typescript
{
  model: "Qwen/Qwen2.5-7B-Instruct",  // 或其他模型
  messages: [
    {
      role: "system",
      content: "你是一个专业的翻译助手,请将用户输入的文本翻译成目标语言。"
    },
    {
      role: "user",
      content: sourceText
    }
  ],
  temperature: 0.3
}
```

**配置项**:
```json
{
  "translator.provider": "youdao" | "siliconflow",
  "translator.siliconflow.apiKey": "",
  "translator.siliconflow.model": "Qwen/Qwen2.5-7B-Instruct",
  "translator.siliconflow.baseUrl": "https://api.siliconflow.cn/v1"
}
```

## 5. 工厂模式

```typescript
class TranslatorFactory {
    static create(provider: string): ITranslationProvider {
        switch(provider) {
            case 'youdao':
                return new YoudaoTranslator();
            case 'siliconflow':
                return new SiliconFlowTranslator();
            default:
                throw new Error(`Unknown translator: ${provider}`);
        }
    }
}
```

## 6. 实现步骤

1. 添加 `openai` npm依赖包
2. 创建翻译接口 `ITranslationProvider`
3. 创建基础翻译类 `BaseTranslator`
4. 将现有有道代码迁移到 `YoudaoTranslator`
5. 实现 `SiliconFlowTranslator` (使用OpenAI SDK)
6. 创建 `TranslatorFactory`
7. 更新 `translator.ts` 主逻辑
8. 更新 `package.json` 配置项
9. 更新 `constants.ts` 常量定义
