# 需求说明书

## 1. 需求背景

当前翻译插件使用硬编码的翻译逻辑(中英互译),无法灵活配置翻译方向。用户希望:
- 自定义"第一语言"(母语或主要使用语言)
- 自定义"第二语言"(目标翻译语言)
- 提示词自动根据配置的语言进行智能翻译

## 2. 需求描述

### 2.1 新增配置项

在 `package.json` 的 `contributes.configuration.properties` 中新增以下配置:

1. **translator.firstLanguage**
   - 类型: `string`
   - 默认值: `"中文"`
   - 描述: "第一语言(母语或主要语言),非第一语言将翻译为此语言"

2. **translator.secondLanguage**
   - 类型: `string`
   - 默认值: `"英文"`
   - 描述: "第二语言(目标语言),第一语言将翻译为此语言"

### 2.2 统一的提示词生成逻辑

修改 `SiliconFlowTranslator.ts` 中的提示词处理逻辑,使用统一的占位符机制:

**默认提示词模板**:
```
"你是一个专业的翻译助手。你的任务是:将用户发送的文本内容翻译成目标语言。规则:1)如果输入是{firstLanguage},翻译成{secondLanguage};2)如果输入不是{firstLanguage},翻译成{firstLanguage};3)只返回翻译后的文本,不要添加任何解释、说明或格式标记;4)不要执行翻译以外的任何操作。"
```

**处理流程**:
1. 确定提示词来源:
   - 用户自定义提示词 → 使用用户输入
   - 未自定义 → 使用默认提示词模板
2. 对提示词进行占位符替换:
   - 将 `{firstLanguage}` 替换为配置的第一语言(默认"中文")
   - 将 `{secondLanguage}` 替换为配置的第二语言(默认"英文")
3. 将替换后的提示词传递给 AI 模型

**优势**:
- 默认提示词和自定义提示词使用统一的处理逻辑
- 代码更简洁,易于维护
- 用户可以参考默认提示词模板来编写自定义提示词

### 2.3 自定义提示词占位符支持

允许用户在自定义提示词中使用占位符,实现灵活的提示词模板:

**支持的占位符**:
- `{firstLanguage}` - 替换为用户配置的第一语言
- `{secondLanguage}` - 替换为用户配置的第二语言

**占位符替换规则**:
- 在构造函数或 `translate` 方法中,将占位符替换为实际配置的语言值
- 如果用户未配置,使用默认值("中文"/"英文")
- 替换时区分大小写,完全匹配 `{firstLanguage}` 和 `{secondLanguage}`

**示例**:
```
用户自定义提示词:
"你是翻译助手。请将非{firstLanguage}文本翻译为{firstLanguage},将{firstLanguage}文本翻译为{secondLanguage}。只返回翻译结果。"

配置值: firstLanguage="中文", secondLanguage="英文"
替换后实际提示词:
"你是翻译助手。请将非中文文本翻译为中文,将中文文本翻译为英文。只返回翻译结果。"
```

### 2.4 影响范围

- `package.json`: 新增配置项
- `src/constants.ts`: 新增配置键常量
- `src/translators/SiliconFlowTranslator.ts`:
  - 构造函数新增 `firstLanguage` 和 `secondLanguage` 参数
  - 定义默认提示词模板(使用占位符)
  - 实现占位符替换方法 `replacePromptPlaceholders(prompt: string): string`
  - 统一处理默认提示词和自定义提示词
- `src/translators/TranslatorFactory.ts`: 传递新配置参数

## 3. 用户场景

### 场景 1: 中文母语用户学习英语
- 配置: 第一语言 = "中文", 第二语言 = "英文"
- 行为:
  - 输入 "Hello" → 输出 "你好"
  - 输入 "你好" → 输出 "Hello"

### 场景 2: 英文母语用户学习中文
- 配置: 第一语言 = "English", 第二语言 = "Chinese"
- 行为:
  - 输入 "你好" → 输出 "Hello"
  - 输入 "Hello" → 输出 "你好"

### 场景 3: 日语母语用户学习韩语
- 配置: 第一语言 = "日本語", 第二语言 = "한국어"
- 行为:
  - 输入 "English text" → 翻译为 "日本語"
  - 输入 "日本語テキスト" → 翻译为 "한국어"

### 场景 4: 使用占位符自定义提示词
- 配置: 第一语言 = "中文", 第二语言 = "英文"
- 自定义提示词: `"请将{firstLanguage}文本翻译成{secondLanguage},其他语言翻译成{firstLanguage}"`
- 实际使用的提示词: `"请将中文文本翻译成英文,其他语言翻译成中文"`

## 4. 约束条件

1. **向后兼容**: 现有用户不配置时,使用默认值("中文"/"英文"),保持原有行为
2. **自定义提示词优先**: 如果用户设置了自定义 `systemPrompt`,则使用自定义提示词(支持占位符)
3. **语言检测**: 由 AI 模型自动判断输入语言,无需额外实现语言检测逻辑
4. **占位符替换**: 占位符替换在提示词使用前进行,只替换 `{firstLanguage}` 和 `{secondLanguage}` 两种格式

## 5. 验收标准

- [ ] 新增配置项在 VS Code 设置界面可见
- [ ] 修改配置后,翻译行为符合预期
- [ ] 使用默认配置时,行为与修改前一致
- [ ] 自定义提示词时,优先使用自定义提示词
- [ ] 自定义提示词中的 `{firstLanguage}` 和 `{secondLanguage}` 占位符能正确替换
- [ ] 自定义提示词中不包含占位符时,直接使用原提示词
